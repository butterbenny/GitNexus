# Deprecated: `gitnexus-debugging`

This skill is phased out.

Use core skills instead:

1. `debug` (`debug_mode`) to localize broken loops.
2. `implement` (`implement_mode`) to apply fixes when needed.
3. `review` (`review_mode`) to validate diff/risk after edits.

Mandatory chain for code changes:

- `debug -> implement -> review`
