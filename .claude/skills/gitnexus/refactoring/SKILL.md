# Deprecated: `gitnexus-refactoring`

This skill is phased out.

Use core skills instead:

1. `query` (`query_mode`) to discover current architecture and touchpoints.
2. `implement` (`implement_mode`) to generate ordered edits.
3. `review` (`review_mode`) to validate blast radius/contracts post-edit.

Mandatory chain for code changes:

- `query -> implement -> review`
